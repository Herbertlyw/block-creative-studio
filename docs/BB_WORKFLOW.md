# BB 工作流

打开页面后新建或导入作品，设置棋盘和供给，记录真人动作或生成机器 Take，再设置素材和音频、预览并保存或导出。保存会发起浏览器下载；浏览器是否完成写盘由用户的浏览器和文件系统决定。

已有参考视频可在“参考视频观察记录”中选择，人工或 Agent 根据画面标注初盘、供给、时间、几何和轨迹，确认后生成可编辑作品。修改已经绑定来源的作品时，在观察编辑器恢复、修改并重新确认受影响内容。当前来源恢复主要支持单 Take；额外的评分、镜头、预拖拽或片尾时间轨道无法同步时会拒绝修改并保留原件。

支持工程内嵌素材，或在导入时选择工程目录、CAS、元素库目录，核验后保存为便携作品。常用图片角色为背景、牌面、棋盘图集；图集可能覆盖棋盘上的牌面。观察外观有 white、coral、cyan 分组图片，程序碎片不一定消费相同图片。声音支持 PCM16 / float32 WAV BGM、落位/消除事件 cue，以及按 Take 秒数定位的人声。“分轨混音与人声”提供素材选择、增益、时间与可选压低；BGM 和人声支持各自合同中的源偏移与淡入淡出，只有 BGM 循环。预混 WAV 无法自动拆轨，替换会影响其中全部声音。详细范围见 [声音混音](AUDIO_MIX.md)。不能解析的资源会报错，不能假定所有效果、图片或 3D 模式可互换。

工作台外观可以保存在作品中。普通作品预览默认跟随已保存设置；修改临时外观后可选择“恢复工程设置”。实际作品修改后需保存；离开时提供保存、放弃或取消，并在刷新关闭时提供浏览器警告。浏览器提示仅表明保存请求已发起。

测试使用 npm test、npm run check、npm run build。浏览器端生成演示输入并验证预览、保存和一段有声视频可执行 npm run test:browser:preview-session。开发格式化可运行 npm run format；运行时依赖目录 `src/nativeReference`、生成输出和依赖包被排除。

音频 AAC 优先使用原生编码器，缺少时按需加载官方软件扩展。动态时间校准使用当前实际编码器，不固定某台设备的延迟。浏览器视频 seek 为近似定位。VFR、任意特效序列、全部历史工程和所有浏览器或 3D 素材组合未覆盖；合成测试不代表真实视频视觉或听感已获得认可。

导出显示素材准备、音频混音、编码能力探测、音频编码、视频帧进度、封装和 AAC 时序校准。没有可靠估算时不显示剩余时间。可以取消并在任务结束后重试；切换作品或退出页面会取消旧任务，晚到的回调不能发布旧视频或覆盖新任务状态。错误包含失败阶段与具体原因。成功仅提示“视频下载已发起”，请检查浏览器是否完成写盘。

观察入口显示播放器近似时间、测量源帧/时间基和校准输出事件帧。普通玩法草稿仍不对齐绝对源时间。生成前列出未知棋盘格、候选、动作与几何轨迹的待确认项；修改前一步动作会撤销下游确认，原始 JSON 编辑也适用。轨迹显示动作 ID、源帧、时间与点序号，ID/顺序不匹配时拒绝确认；可以在 ID 集合一致时显式重排，不删除轨迹绕过校验。标注修改后旧生成快照失效；另存观察草稿后可以重开，并重新核验源视频哈希。
